СРМ / ЕЖЕНЕДЕЛЬНЫЙ ПРОГРЕСС ПРОЕКТА

Тема проекта: Платформа оценки надежности LLM-систем (LLM Reliability Analytics)
Студент: Нурланов Нурбол
Период отчета: 1–7 недели (шаблон формата СРМ)

============================================================
1 НЕДЕЛЯ. АНАЛИЗ ТРЕБОВАНИЙ И ПОСТАНОВКА ЗАДАЧИ
============================================================

Задание:
- Сформулировать цель проекта
- Определить входные/выходные данные
- Зафиксировать минимальные требования к системе

Результат:
Сформулирована цель: построить воспроизводимую систему оценки надежности LLM на основе:
- структурированных тест-кейсов,
- oracle-проверок корректности,
- агрегированных метрик качества,
- хранения результатов в локальной аналитической БД.

Определены ключевые сущности:
- TestCase (вопрос, ожидаемый ответ, тип oracle, источник теста)
- TestRun (метаданные запуска: модель, провайдер, режим, версия датасета)
- TestResult (фактический ответ, score, latency, ошибка)
- ReliabilityReport (агрегированные метрики)

Критерии MVP:
- загрузка JSONL/CSV
- запуск батча через CLI
- оценка oracle-движком
- сохранение результатов в DuckDB
- визуализация в Streamlit

- sample_test_cases.jsonl
- llm_eval_dataset_v2_300.jsonl
- llm_eval_dataset_v2_300.parquet

5 НЕДЕЛЯ. RUNNER + ORACLE ENGINE
============================================================

Задание:
- Реализовать запуск тест-кейсов на LLM
- Поддержать oracle-оценивание с объяснимостью
- Сохранять latency и ошибки

Результат:
Реализованы клиенты:
- MockLLMClient (fallback/отладка)
- OllamaLLMClient (локальный реальный запуск)

Реализован TestRunner:
- повторные прогоны (repeats_per_case)
- замер latency
- устойчивое поведение при ошибках вызова

Реализован oracle engine с детализированным результатом:
- exact_match, regex_match, keyword_match, numeric_tolerance, json_schema
- placeholder semantic_similarity
- composite-правила
- нормализация ответов
- details для трассировки решения oracle

Пример кода (контракт oracle):

class OracleEvaluation(BaseModel):
    is_correct: bool
    score: float
    error_type: str | None = None
    explanation: str | None = None
    details: dict[str, Any] = Field(default_factory=dict)

Пример терминала (локальные модели):
